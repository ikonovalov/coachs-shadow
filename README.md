# Coach's Shadow

Telegram-бот велоклуба: расписание тренировок, публикация постов в чаты уровней за 24 часа до старта,
запись «Пойду / Не пойду» с лимитом мест, напоминания за 2 часа, отмена и автоматическое закрытие тренировок.

Стек: Python 3.11+, aiogram 3, SQLAlchemy 2 (async) + aiosqlite, Alembic, pydantic-settings, pytest.
Дизайн: `docs/superpowers/specs/2026-10-06-coachs-shadow-design.md`.

## Установка

Windows (PowerShell):

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -e ".[dev]"
```

Linux / macOS:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
```

## Настройка

Скопируйте `.env.example` в `.env` и заполните:

| Переменная | Назначение |
|---|---|
| `BOT_TOKEN` | токен бота от @BotFather |
| `ADMIN_IDS` | Telegram ID администраторов через запятую (свой ID покажет команда `/whoami`) |
| `DATABASE_URL` | по умолчанию `sqlite+aiosqlite:///coachs_shadow.db` |
| `CLUB_TIMEZONE` | часовой пояс клуба (IANA), по умолчанию `Europe/Moscow` |

## Запуск

```bash
alembic upgrade head      # создать/обновить схему БД
python -m bot.main        # запустить бота (long polling + планировщик)
```

Демо-данные для проверки (одна тренировка на завтра 19:00 для уровня «Новички»):

```bash
python -m scripts.seed_demo
```

Тренировки создаются в личке с ботом: `/trainer` → «➕ Новая серия» (по дням недели) или «➕ Разовая».

### Доступ к боту

Личка с ботом работает только для участников клуба — тех, кто состоит хотя бы в одном привязанном чате
(`/bind_level`). Остальным бот отвечает «Бот доступен участникам клуба». Администраторы из `ADMIN_IDS`
проверку не проходят, `/whoami` и ссылка-приглашение тренера доступны всем. Членство проверяется через
`getChatMember`, поэтому бот должен состоять в каждой привязанной группе; нажатие кнопки под постом
в группе тоже засчитывается как подтверждение членства.

### Ручная проверка

1. Добавьте бота в тестовую группу (он должен иметь право писать).
2. В группе отправьте `/bind_level Новички` (от администратора) — чат привязан к уровню.
3. В течение ~30 секунд в группе появится пост тренировки; кнопка «Пойду» меняет счётчик, «Участники» показывает список.
4. В личке с ботом `/schedule` показывает ближайшие тренировки (нужно состоять в привязанной группе,
   иначе бот ответит «Бот доступен участникам клуба»; администраторы из `ADMIN_IDS` — без проверки).

Сценарий тренера:

1. Администратор: `/admin` → «🔗 Приглашение тренера», отправляет ссылку будущему тренеру.
2. Тренер открывает ссылку — получает роль тренера.
3. Администратор: `/admin` → «💬 Чаты» → чат → «➕ Добавить тренера» (первый тренер чата становится главным).
4. Тренер: `/trainer` → «➕ Новая серия» или «➕ Разовая», заполняет форму, «✅ Создать».
5. Пост появится в чате за 24 часа до старта (окно меняется в `/admin` → «⚙️ Настройки»).

### Команды

- `/start`, `/whoami`, `/schedule` — для всех (в личке; `/whoami` везде)
- `/trainer` — тренер, в личке: мои тренировки (отмена, в т.ч. нескольких сразу; правка места, описания,
  лимита; правка всей серии; участники — записать/убрать вручную), новая серия или разовая тренировка, мои чаты
- `/admin` — администратор, в личке: тренеры, администраторы, уровни, чаты (тренеры чата, главный тренер),
  ссылка-приглашение тренера, настройки (окно публикации, напоминание, длительность, часовой пояс)
- `https://t.me/<бот>?start=trainer_<токен>` — одноразовая ссылка-приглашение тренера (создаётся в `/admin`,
  действует 24 часа). Меню тренера откроется, когда администратор добавит тренера в чат клуба
- `/add_level <название>` — администратор, добавить уровень
- `/bind_level <название>` — администратор, в группе: привязать чат к уровню

Любая команда прерывает незаконченную форму или ввод.

### Дерево меню

Меню в личке с ботом — inline-кнопки; на каждом экране есть «⬅️ Меню» / «⬅️ Назад». Кнопки под постом
тренировки в чате: «✅ Пойду», «❌ Не пойду», «👥 Участники».

```
/trainer — меню тренера
├── 📋 Мои тренировки
│   ├── <тренировка>
│   │   ├── 🗑 Отменить → подтверждение
│   │   ├── ✏️ Место / ✏️ Описание / ✏️ Лимит → ввод значения
│   │   ├── 👥 Участники → ❌ <участник> (убрать) · ➕ Записать участника
│   │   └── 🔁 Изменить серию → тип, место, описание, лимит, дни, время, окончание → подтверждение
│   └── 🗑 Отменить несколько → выбор → подтверждение
├── ➕ Новая серия / ➕ Разовая
│   └── тип → место → уровни → дни недели (серия) или дата (разовая) → время
│       → дата окончания (серия) → лимит → описание → проверка → ✅ Создать
└── 💬 Мои чаты → <чат> → ⭐ Главным · ➕ Добавить тренера · убрать тренера

/admin — меню администратора
├── 👥 Тренеры → снять тренера · ➕ Назначить тренера
├── 🛡 Админы → снять админа · ➕ Назначить админа
├── 🎚 Уровни → ➕ Добавить уровень
├── 💬 Чаты → <чат> → ⭐ Главным · ➕ Добавить тренера · убрать тренера
├── 🔗 Приглашение тренера → одноразовая ссылка на 24 часа
└── ⚙️ Настройки → окно публикации, напоминание, длительность, часовой пояс
```

## Тесты

```bash
python -m pytest -q                      # все тесты
python -m pytest tests/schedule -v       # одна папка
python -m pytest -k concurrent           # по имени
```

Сеть и токен не нужны: сервисные тесты работают на временной SQLite, Telegram подменён `FakeMessenger`
(`tests/fakes.py`). Если окружение не активировано, запускайте через `.venv\Scripts\python -m pytest`.

## Миграции

```bash
alembic revision --autogenerate -m "описание"   # после изменения моделей
alembic upgrade head
```

Новые модели должны быть импортированы в `bot/registry.py`.

## Структура

```
bot/
  core/          конфиг, БД, ошибки, настройки, Messenger-протокол, права
  users/ schedule/ participation/ publishing/ jobs/   фичи (models, service, ...)
  usecases.py    операции, затрагивающие несколько фич
  telegram/      единственный пакет, который импортирует aiogram
  bootstrap.py   main.py
alembic/         миграции
scripts/         seed_demo.py
tests/           зеркалит bot/
```

Правила: фичи зависят от `core`, не импортируют aiogram; в Telegram ходим только через `Messenger`;
время хранится в UTC, правила повторения считаются в `club_timezone`.
