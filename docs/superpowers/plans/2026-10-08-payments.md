# Оплата тренировок и абонементы — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Бот ведёт учёт оплаты: цены, абонементы на набор серий, начисления при закрытии тренировки, посещение с возвратами, экраны ученика, админа и тренера.

**Architecture:** Новый feature-пакет `bot/billing` (модели `PriceRule`, `SubscriptionPlan`, `Subscription`, `Charge`, `Attendance`; сервисы `CatalogService`, `BillingService`, `BillingViews`). Закрытие тренировки, правка посещения и отметки об оплате проходят через `bot/usecases.py`. Остаток абонемента и статусы начислений меняются только условным `UPDATE` с проверкой rowcount. Telegram-слой: три новых роутера (`payments`, `pay_admin`, `attendance`).

**Tech Stack:** Python 3.11+, aiogram 3, SQLAlchemy 2 async + aiosqlite, Alembic, pytest (`asyncio_mode = "auto"`).

**Spec:** `docs/superpowers/specs/2026-10-08-payments-design.md`

## Global Constraints

- Суммы в **копейках** (`int`), время в **UTC** (`UTCDateTime`), повторения и «календарный месяц» считаются в `club_timezone`.
- aiogram импортируется только в `bot/telegram/`; `bot/billing` aiogram не знает.
- Фичи не импортируют **сервисы** друг друга. Допустимо делиться **моделями** и **read-хелперами** (`bot/schedule/queries.py`, `bot/billing/queries.py`) и чистыми функциями из `bot/core`.
- Все изменения состояния, которые обновляют посты или уведомляют людей, идут через `bot/usecases.py`; обработчики вызывают именно их.
- Права проверяются в сервисах (`require_admin`, `can_manage`), не в callback-данных.
- Денежные действия (цены, тарифы, выдача абонементов, отметки оплаты и возврата) — только админ. Тренер (и админ) отмечает посещение, окно 72 часа от конца тренировки, админу окно не ограничено.
- Обработчики Telegram: `take_form` до сервиса, `restore_form` при `DomainError`, экраны через `safe_edit`, каждый роутер заканчивается catch-all `<prefix>:`.
- Удаление тарифов — по образцу «Админов»: `❌ <имя>` → подтверждение → сервис удаляет → список перерисовывается.
- Обработчики задач идемпотентны; логирование через `logging.getLogger(__name__)`.
- Новые модели импортируются в `bot/registry.py`.
- Тесты: `python -m pytest -q` (сеть и токен не нужны). Коммит-трейлер: `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.

## Отличия от спеки (внесены в спеку в Task 1)

- `SubscriptionPlan.valid_days` → `valid_months` (срок считается в календарных месяцах; `NULL` = бессрочный, по умолчанию 1).
- Добавлена таблица `Attendance` (явные отметки посещения), а `Charge` получает `ref_id` (0 для `session`/`surcharge`, id заказа для `inventory`), чтобы уникальность `(training_id, user_id, kind, ref_id)` работала и для нескольких единиц инвентаря.
- `Subscription` хранит `name` вместо ссылки на тариф (тариф можно удалить, выданные абонементы не меняются).
- Сервисы: `CatalogService` (цены, тарифы), `BillingService` (выдача, начисления, оплата, посещение), `BillingViews` (чтение). Префиксы callback: `pay:*` (админ), `att:*` (посещение).
- Цены, которых не было при создании тренировки (`NULL`), берутся при закрытии из серии/типа на тот момент.
- **Не входит** (сознательно отложено, скажите — добавлю): правка тарифа (вместо неё — удалить и создать заново), напоминания о долгах и истечении.

```python
from datetime import datetime

from sqlalchemy import BigInteger, Boolean, ForeignKey, Integer, String, UniqueConstraint
from sqlalchemy.orm import Mapped, mapped_column

from bot.core.db import Base, UTCDateTime


class ChargeKind:
    SESSION = "session"
    SURCHARGE = "surcharge"
    INVENTORY = "inventory"


class ChargeStatus:
    PENDING = "pending"  # долг
    COVERED = "covered"  # списано с абонемента
    PAID = "paid"
    VOID = "void"  # не засчитано


class PriceRule(Base):
    """Цены по умолчанию для типа тренировки (kind). None — не задано."""

    __tablename__ = "price_rules"

    kind: Mapped[str] = mapped_column(String(16), primary_key=True)
    single_price: Mapped[int | None] = mapped_column(Integer)
    surcharge_per_person: Mapped[int | None] = mapped_column(Integer)


class SubscriptionPlan(Base):
    __tablename__ = "subscription_plans"

    id: Mapped[int] = mapped_column(primary_key=True)
    name: Mapped[str] = mapped_column(String(100))
    sessions: Mapped[int] = mapped_column(Integer)
    price: Mapped[int] = mapped_column(Integer)
    valid_months: Mapped[int | None] = mapped_column(Integer)  # None — бессрочный


class SubscriptionPlanSeries(Base):
    __tablename__ = "subscription_plan_series"

    plan_id: Mapped[int] = mapped_column(ForeignKey("subscription_plans.id"), primary_key=True)
    series_id: Mapped[int] = mapped_column(ForeignKey("training_series.id"), primary_key=True)


class Subscription(Base):
    """Выданный абонемент. Название, цена и набор серий скопированы из тарифа при выдаче."""

    __tablename__ = "subscriptions"

    id: Mapped[int] = mapped_column(primary_key=True)
    user_id: Mapped[int] = mapped_column(BigInteger, ForeignKey("users.telegram_id"), index=True)
    name: Mapped[str] = mapped_column(String(100))
    sessions_total: Mapped[int] = mapped_column(Integer)
    sessions_left: Mapped[int] = mapped_column(Integer)
    starts_at: Mapped[datetime] = mapped_column(UTCDateTime)
    expires_at: Mapped[datetime | None] = mapped_column(UTCDateTime)  # None — бессрочный
    price: Mapped[int] = mapped_column(Integer)
    paid_at: Mapped[datetime | None] = mapped_column(UTCDateTime)
    paid_by: Mapped[int | None] = mapped_column(BigInteger, ForeignKey("users.telegram_id"))
    issued_by: Mapped[int] = mapped_column(BigInteger, ForeignKey("users.telegram_id"))
    created_at: Mapped[datetime] = mapped_column(UTCDateTime)


class SubscriptionSeries(Base):
    __tablename__ = "subscription_series"

    subscription_id: Mapped[int] = mapped_column(ForeignKey("subscriptions.id"), primary_key=True)
    series_id: Mapped[int] = mapped_column(ForeignKey("training_series.id"), primary_key=True)


class Charge(Base):
    __tablename__ = "charges"
    __table_args__ = (UniqueConstraint("training_id", "user_id", "kind", "ref_id", name="uq_charge_key"),)

    id: Mapped[int] = mapped_column(primary_key=True)
    user_id: Mapped[int] = mapped_column(BigInteger, ForeignKey("users.telegram_id"), index=True)
    training_id: Mapped[int] = mapped_column(ForeignKey("trainings.id"), index=True)
    kind: Mapped[str] = mapped_column(String(16))
    ref_id: Mapped[int] = mapped_column(Integer, default=0)  # inventory: id заказа; иначе 0
    amount: Mapped[int] = mapped_column(Integer)
    status: Mapped[str] = mapped_column(String(16), default=ChargeStatus.PENDING, index=True)
    subscription_id: Mapped[int | None] = mapped_column(ForeignKey("subscriptions.id"))
    paid_at: Mapped[datetime | None] = mapped_column(UTCDateTime)
    paid_by: Mapped[int | None] = mapped_column(BigInteger, ForeignKey("users.telegram_id"))
    refund_due: Mapped[bool] = mapped_column(Boolean, default=False)
    refunded_at: Mapped[datetime | None] = mapped_column(UTCDateTime)
    created_at: Mapped[datetime] = mapped_column(UTCDateTime)


class Attendance(Base):
    """Явная отметка посещения. Нет строки — считается, что записавшийся («Пойду») пришёл."""

    __tablename__ = "attendance"

    training_id: Mapped[int] = mapped_column(ForeignKey("trainings.id"), primary_key=True)
    user_id: Mapped[int] = mapped_column(BigInteger, ForeignKey("users.telegram_id"), primary_key=True)
    present: Mapped[bool] = mapped_column(Boolean)
    marked_by: Mapped[int] = mapped_column(BigInteger, ForeignKey("users.telegram_id"))
    marked_at: Mapped[datetime] = mapped_column(UTCDateTime)
```

```python
"""Деньги хранятся в копейках (int); ввод и вывод — в рублях."""
from decimal import Decimal, InvalidOperation

from bot.core.errors import InvalidAction

MAX_RUBLES = 1_000_000
MONEY_HINT = "Введите сумму в рублях, например 700 или 700,50"


def _amount(kopecks: int) -> str:
    sign = "-" if kopecks < 0 else ""
    rub, kop = divmod(abs(kopecks), 100)
    return f"{sign}{rub}" if kop == 0 else f"{sign}{rub},{kop:02d}"


def format_money(kopecks: int) -> str:
    return f"{_amount(kopecks)} ₽"


def format_range(low: int, high: int) -> str:
    return format_money(low) if low == high else f"{_amount(low)}–{format_money(high)}"


def parse_money(text: str) -> int:
    try:
        value = Decimal(text.strip().replace(",", ".").replace(" ", ""))
    except InvalidOperation:
        raise InvalidAction(MONEY_HINT) from None
    if not value.is_finite() or value < 0 or value > MAX_RUBLES:
        raise InvalidAction(MONEY_HINT)
    kopecks = value * 100
    if kopecks != kopecks.to_integral_value():
        raise InvalidAction(MONEY_HINT)
    return int(kopecks)


def surcharge_share(tariff: int, attendees: int) -> int:
    """Доля доплаты на одного пришедшего: тариф платят все, включая тренера, а его часть делят ученики."""
    n = max(attendees, 1)
    return -(-tariff * (n + 1) // n)  # деление с округлением вверх до копейки


def surcharge_estimate(tariff: int, going: int, capacity: int | None) -> tuple[int, int]:
    """Ориентир (меньше, больше): с полной группой и с текущим числом записавшихся."""
    high = surcharge_share(tariff, going)
    low = surcharge_share(tariff, capacity) if capacity and capacity > going else high
    return low, high
```

```python
from zoneinfo import ZoneInfo


def add_months(day: date, months: int) -> date:
    index = day.month - 1 + months
    year, month = day.year + index // 12, index % 12 + 1
    return date(year, month, min(day.day, calendar.monthrange(year, month)[1]))


def subscription_expiry(now: datetime, months: int | None, tz: ZoneInfo) -> datetime | None:
    """Конец локального дня через `months` календарных месяцев, в UTC. None — бессрочный."""
    if months is None:
        return None
    last_day = add_months(now.astimezone(tz).date(), months)
    return datetime.combine(last_day, time(23, 59, 59), tzinfo=tz).astimezone(timezone.utc)
```

```python
from sqlalchemy import delete, select
from sqlalchemy.ext.asyncio import AsyncSession

from bot.billing.models import PriceRule, SubscriptionPlan, SubscriptionPlanSeries
from bot.billing.queries import Prices
from bot.core.errors import InvalidAction, NotFound
from bot.core.permissions import require_admin
from bot.schedule.models import TrainingKind, TrainingSeries
from bot.users.models import User

MAX_PLAN_NAME = 100


def _check_prices(prices: Prices) -> None:
    for value in (prices.single_price, prices.surcharge_per_person):
        if value is not None and value < 0:
            raise InvalidAction("Сумма не может быть отрицательной")


class CatalogService:
    """Цены по типу и серии, тарифы абонементов. Меняет только админ."""

    def __init__(self, session: AsyncSession) -> None:
        self.session = session

    async def type_prices(self, kind: str) -> Prices:
        rule = await self.session.get(PriceRule, kind)
        return Prices(rule.single_price, rule.surcharge_per_person) if rule else Prices()

    async def set_type_prices(self, actor: User, kind: str, prices: Prices) -> None:
        require_admin(actor)
        if kind not in TrainingKind.ALL:
            raise NotFound("Неизвестный тип тренировки")
        _check_prices(prices)
        rule = await self.session.get(PriceRule, kind)
        if rule is None:
            rule = PriceRule(kind=kind)
            self.session.add(rule)
        rule.single_price = prices.single_price
        rule.surcharge_per_person = prices.surcharge_per_person
        await self.session.commit()

    async def set_series_prices(self, actor: User, series_id: int, prices: Prices) -> None:
        require_admin(actor)
        _check_prices(prices)
        series = await self.session.get(TrainingSeries, series_id)
        if series is None:
            raise NotFound("Серия не найдена")
        series.single_price = prices.single_price
        series.surcharge_per_person = prices.surcharge_per_person
        await self.session.commit()

    async def create_plan(
        self, actor: User, name: str, sessions: int, price: int, valid_months: int | None, series_ids: list[int]
    ) -> SubscriptionPlan:
        require_admin(actor)
        name = name.strip()
        if not name or len(name) > MAX_PLAN_NAME:
            raise InvalidAction(f"Название — от 1 до {MAX_PLAN_NAME} символов")
        if not 1 <= sessions <= 100:
            raise InvalidAction("Занятий — от 1 до 100")
        if price < 0:
            raise InvalidAction("Цена не может быть отрицательной")
        if valid_months is not None and not 1 <= valid_months <= 24:
            raise InvalidAction("Срок — от 1 до 24 месяцев или бессрочный")
        ids = sorted(set(series_ids))
        if not ids:
            raise InvalidAction("Выберите хотя бы одну серию")
        found = set(await self.session.scalars(select(TrainingSeries.id).where(TrainingSeries.id.in_(ids))))
        if found != set(ids):
            raise NotFound("Серия не найдена")
        plan = SubscriptionPlan(name=name, sessions=sessions, price=price, valid_months=valid_months)
        self.session.add(plan)
        await self.session.flush()
        for series_id in ids:
            self.session.add(SubscriptionPlanSeries(plan_id=plan.id, series_id=series_id))
        await self.session.commit()
        return plan

    async def list_plans(self) -> list[SubscriptionPlan]:
        return list(await self.session.scalars(select(SubscriptionPlan).order_by(SubscriptionPlan.id)))

    async def plan_series(self, plan_id: int) -> list[TrainingSeries]:
        rows = await self.session.scalars(
            select(TrainingSeries)
            .join(SubscriptionPlanSeries, SubscriptionPlanSeries.series_id == TrainingSeries.id)
            .where(SubscriptionPlanSeries.plan_id == plan_id)
            .order_by(TrainingSeries.id)
        )
        return list(rows)

    async def delete_plan(self, actor: User, plan_id: int) -> SubscriptionPlan:
        """Выданные абонементы не меняются: название, цена и набор серий скопированы при выдаче."""
        require_admin(actor)
        plan = await self.session.get(SubscriptionPlan, plan_id)
        if plan is None:
            raise NotFound("Тариф не найден")
        await self.session.execute(delete(SubscriptionPlanSeries).where(SubscriptionPlanSeries.plan_id == plan_id))
        await self.session.delete(plan)
        await self.session.commit()
        return plan
```

```python
async def candidate_subscription_ids(session: AsyncSession, training: Training, user_id: int) -> list[int]:
    """Абонементы ученика, которыми можно закрыть тренировку: серия в наборе, есть остаток, выдан до старта,
    срок не истёк к старту. Сначала истекающие раньше, бессрочные последними."""
    rows = await session.scalars(
        select(Subscription.id)
        .join(SubscriptionSeries, SubscriptionSeries.subscription_id == Subscription.id)
        .where(
            Subscription.user_id == user_id,
            SubscriptionSeries.series_id == training.series_id,
            Subscription.sessions_left > 0,
            Subscription.starts_at <= training.starts_at,
            or_(Subscription.expires_at.is_(None), Subscription.expires_at >= training.starts_at),
        )
        .order_by(Subscription.expires_at.is_(None), Subscription.expires_at, Subscription.id)
    )
    return list(rows)
```

```python
import logging
from datetime import datetime
from zoneinfo import ZoneInfo

from sqlalchemy import select, update
from sqlalchemy.exc import IntegrityError
from sqlalchemy.ext.asyncio import AsyncSession

from bot.billing.models import (
    Attendance,
    Charge,
    ChargeKind,
    ChargeStatus,
    Subscription,
    SubscriptionPlan,
    SubscriptionPlanSeries,
    SubscriptionSeries,
)
from bot.billing.pricing import subscription_expiry
from bot.billing.queries import Prices, candidate_subscription_ids, resolve_prices
from bot.core.errors import NotFound
from bot.core.money import surcharge_share
from bot.core.permissions import require_admin
from bot.core.settings import get_setting
from bot.inventory.models import InventoryOrder, OrderStatus
from bot.participation.models import Participation, ParticipationStatus
from bot.schedule.models import Training, TrainingSeries, TrainingStatus
from bot.users.models import User

log = logging.getLogger(__name__)


class BillingService:
    """Выдача абонементов, начисления, оплата и посещение. Остаток абонемента и статусы начислений меняются
    только условным UPDATE с проверкой rowcount (см. ARCHITECTURE.md §8)."""

    def __init__(self, session: AsyncSession) -> None:
        self.session = session

    # ---- абонементы ----

    async def issue_subscription(
        self, actor: User, user_id: int, plan_id: int, *, paid: bool, now: datetime
    ) -> Subscription:
        require_admin(actor)
        plan = await self.session.get(SubscriptionPlan, plan_id)
        if plan is None:
            raise NotFound("Тариф не найден")
        if await self.session.get(User, user_id) is None:
            raise NotFound("Пользователь не найден")
        series_ids = list(
            await self.session.scalars(
                select(SubscriptionPlanSeries.series_id)
                .where(SubscriptionPlanSeries.plan_id == plan_id)
                .order_by(SubscriptionPlanSeries.series_id)
            )
        )
        tz = ZoneInfo(await get_setting(self.session, "club_timezone"))
        sub = Subscription(
            user_id=user_id,
            name=plan.name,
            sessions_total=plan.sessions,
            sessions_left=plan.sessions,
            starts_at=now,
            expires_at=subscription_expiry(now, plan.valid_months, tz),
            price=plan.price,
            paid_at=now if paid else None,
            paid_by=actor.telegram_id if paid else None,
            issued_by=actor.telegram_id,
            created_at=now,
        )
        self.session.add(sub)
        await self.session.flush()
        for series_id in series_ids:
            self.session.add(SubscriptionSeries(subscription_id=sub.id, series_id=series_id))
        await self.session.commit()
        log.info("subscription %s issued to %s by %s (paid=%s)", sub.id, user_id, actor.telegram_id, paid)
        return sub

    # ---- начисления ----

    async def attendee_ids(self, training_id: int) -> list[int]:
        """Кто считается пришедшим: записавшиеся без отметки «не пришёл» и отмеченные «пришёл» без записи."""
        going = list(
            await self.session.scalars(
                select(Participation.user_id)
                .where(Participation.training_id == training_id, Participation.status == ParticipationStatus.GOING)
                .order_by(Participation.updated_at, Participation.user_id)
            )
        )
        marks = {
            user_id: present
            for user_id, present in await self.session.execute(
                select(Attendance.user_id, Attendance.present).where(Attendance.training_id == training_id)
            )
        }
        result = [uid for uid in going if marks.get(uid, True)]
        result += sorted(uid for uid, present in marks.items() if present and uid not in going)
        return result

    async def charge_training(self, training_id: int, now: datetime) -> list[Charge]:
        """Начисления за закрытую тренировку. Идемпотентно: уже созданное пропускается (уникальный ключ Charge).
        Возвращает только начисления, созданные этим вызовом."""
        training = await self.session.get(Training, training_id)
        if training is None or training.status != TrainingStatus.DONE:
            return []
        prices = await self._prices(training)
        attendees = await self.attendee_ids(training_id)
        share = surcharge_share(prices.surcharge_per_person, len(attendees)) if prices.surcharge_per_person else None
        created: list[Charge] = []
        for user_id in attendees:
            created += await self._charge_participant(training, user_id, prices, share, now)
        log.info("charged training %s: %d new charge(s)", training_id, len(created))
        return created

    async def _prices(self, training: Training) -> Prices:
        """Снимок цен тренировки; отсутствующие поля берутся из серии/типа на текущий момент."""
        if training.single_price is not None and training.surcharge_per_person is not None:
            return Prices(training.single_price, training.surcharge_per_person)
        series = await self.session.get(TrainingSeries, training.series_id)
        resolved = await resolve_prices(self.session, series)
        return Prices(
            training.single_price if training.single_price is not None else resolved.single_price,
            training.surcharge_per_person if training.surcharge_per_person is not None else resolved.surcharge_per_person,
        )

    async def _take_unit(self, training: Training, user_id: int) -> int | None:
        for sub_id in await candidate_subscription_ids(self.session, training, user_id):
            taken = await self.session.execute(
                update(Subscription)
                .where(Subscription.id == sub_id, Subscription.sessions_left > 0)
                .values(sessions_left=Subscription.sessions_left - 1)
                .execution_options(synchronize_session="fetch")
            )
            if taken.rowcount == 1:
                return sub_id
        return None

    async def _charge_participant(
        self, training: Training, user_id: int, prices: Prices, share: int | None, now: datetime, *,
        commit: bool = True,
    ) -> list[Charge]:
        existing = {
            (kind, ref_id)
            for kind, ref_id in await self.session.execute(
                select(Charge.kind, Charge.ref_id).where(Charge.training_id == training.id, Charge.user_id == user_id)
            )
        }

        def new(kind: str, amount: int, status: str, ref_id: int = 0, subscription_id: int | None = None) -> Charge:
            return Charge(
                user_id=user_id, training_id=training.id, kind=kind, ref_id=ref_id, amount=amount, status=status,
                subscription_id=subscription_id, created_at=now,
            )

        created: list[Charge] = []
        if (ChargeKind.SESSION, 0) not in existing:
            sub_id = await self._take_unit(training, user_id)
            if sub_id is not None:
                created.append(new(ChargeKind.SESSION, prices.single_price or 0, ChargeStatus.COVERED, subscription_id=sub_id))
            elif prices.single_price:
                created.append(new(ChargeKind.SESSION, prices.single_price, ChargeStatus.PENDING))
        if share and (ChargeKind.SURCHARGE, 0) not in existing:
            created.append(new(ChargeKind.SURCHARGE, share, ChargeStatus.PENDING))
        orders = await self.session.scalars(
            select(InventoryOrder).where(
                InventoryOrder.training_id == training.id,
                InventoryOrder.user_id == user_id,
                InventoryOrder.status == OrderStatus.ACTIVE,
                InventoryOrder.price.is_not(None),
                InventoryOrder.price > 0,
            )
        )
        for order in list(orders):
            if (ChargeKind.INVENTORY, order.id) not in existing:
                created.append(new(ChargeKind.INVENTORY, order.price, ChargeStatus.PENDING, ref_id=order.id))
        if not created:
            return []
        self.session.add_all(created)
        if not commit:
            await self.session.flush()
            return created
        try:
            await self.session.commit()
        except IntegrityError:  # параллельный запуск успел раньше: откат вернёт и списанную единицу
            await self.session.rollback()
            return []
        return created
```

```python
from dataclasses import dataclass
from datetime import datetime

from sqlalchemy import func, or_, select
from sqlalchemy.ext.asyncio import AsyncSession

from bot.billing.models import Attendance, Charge, ChargeStatus, Subscription
from bot.billing.queries import Prices, candidate_subscription_ids, resolve_prices
from bot.core.money import format_money, format_range, surcharge_estimate

from bot.schedule.models import Training, TrainingSeries, TrainingStatus
from bot.users.models import User

HISTORY_LIMIT = 10


@dataclass(frozen=True)
class Debtor:
    user: User
    total: int


@dataclass(frozen=True)
class DebtView:
    charges: list[tuple[Charge, Training]]
    subscriptions: list[Subscription]
    total: int


@dataclass(frozen=True)
class MyBilling:
    subscriptions: list[Subscription]
    debts: DebtView
    history: list[tuple[Charge, Training]]


class BillingViews:
    """Только чтение: списки и подсказки для экранов."""

    def __init__(self, session: AsyncSession) -> None:
        self.session = session

    async def debtors(self) -> list[Debtor]:
        totals: dict[int, int] = {}
        pending = await self.session.execute(
            select(Charge.user_id, func.sum(Charge.amount))
            .where(Charge.status == ChargeStatus.PENDING)
            .group_by(Charge.user_id)
        )
        unpaid = await self.session.execute(
            select(Subscription.user_id, func.sum(Subscription.price))
            .where(Subscription.paid_at.is_(None), Subscription.price > 0)
            .group_by(Subscription.user_id)
        )
        for user_id, total in [*pending, *unpaid]:
            totals[user_id] = totals.get(user_id, 0) + total
        if not totals:
            return []
        users = await self.session.scalars(select(User).where(User.telegram_id.in_(totals)).order_by(User.name))
        return [Debtor(user, totals[user.telegram_id]) for user in users if totals[user.telegram_id] > 0]

    async def user_debts(self, user_id: int) -> DebtView:
        charges = [
            (charge, training)
            for charge, training in await self.session.execute(
                select(Charge, Training)
                .join(Training, Training.id == Charge.training_id)
                .where(Charge.user_id == user_id, Charge.status == ChargeStatus.PENDING)
                .order_by(Training.starts_at, Charge.id)
            )
        ]
        subscriptions = list(
            await self.session.scalars(
                select(Subscription)
                .where(Subscription.user_id == user_id, Subscription.paid_at.is_(None), Subscription.price > 0)
                .order_by(Subscription.id)
            )
        )
        total = sum(c.amount for c, _ in charges) + sum(s.price for s in subscriptions)
        return DebtView(charges, subscriptions, total)

    async def my_overview(self, user_id: int, now: datetime) -> MyBilling:
        subscriptions = list(
            await self.session.scalars(
                select(Subscription)
                .where(
                    Subscription.user_id == user_id,
                    Subscription.sessions_left > 0,
                    or_(Subscription.expires_at.is_(None), Subscription.expires_at > now),
                )
                .order_by(Subscription.expires_at.is_(None), Subscription.expires_at, Subscription.id)
            )
        )
        history = [
            (charge, training)
            for charge, training in await self.session.execute(
                select(Charge, Training)
                .join(Training, Training.id == Charge.training_id)
                .where(Charge.user_id == user_id, Charge.status != ChargeStatus.PENDING)
                .order_by(Training.starts_at.desc(), Charge.id.desc())
                .limit(HISTORY_LIMIT)
            )
        ]
        return MyBilling(subscriptions, await self.user_debts(user_id), history)

    async def refunds_due(self) -> list[tuple[Charge, User, Training]]:
        rows = await self.session.execute(
            select(Charge, User, Training)
            .join(User, User.telegram_id == Charge.user_id)
            .join(Training, Training.id == Charge.training_id)
            .where(Charge.status == ChargeStatus.VOID, Charge.refund_due.is_(True), Charge.refunded_at.is_(None))
            .order_by(Charge.id)
        )
        return [(charge, user, training) for charge, user, training in rows]

    async def roster(self, training_id: int) -> list[tuple[User, bool]]:
        """Список для экрана посещения: записавшиеся и отмеченные вручную, с текущей отметкой «пришёл»."""
        going = list(
            await self.session.scalars(
                select(Participation.user_id)
                .where(Participation.training_id == training_id, Participation.status == ParticipationStatus.GOING)
                .order_by(Participation.updated_at, Participation.user_id)
            )
        )
        marks = {
            row.user_id: row
            for row in await self.session.scalars(select(Attendance).where(Attendance.training_id == training_id))
        }
        extra = [uid for uid, _ in sorted(marks.items(), key=lambda kv: (kv[1].marked_at, kv[0])) if uid not in going]
        ids = going + extra
        if not ids:
            return []
        users = {u.telegram_id: u for u in await self.session.scalars(select(User).where(User.telegram_id.in_(ids)))}
        return [(users[uid], marks[uid].present if uid in marks else True) for uid in ids if uid in users]

    async def payment_hint(self, training_id: int, user_id: int, now: datetime) -> str | None:
        """Что ждёт ученика на этой тренировке: списание с абонемента или сумма, плюс ориентир по доплате."""
        training = await self.session.get(Training, training_id)
        if training is None or training.status != TrainingStatus.SCHEDULED:
            return None
        series = await self.session.get(TrainingSeries, training.series_id)
        resolved = await resolve_prices(self.session, series)
        prices = Prices(
            training.single_price if training.single_price is not None else resolved.single_price,
            training.surcharge_per_person if training.surcharge_per_person is not None else resolved.surcharge_per_person,
        )
        lines: list[str] = []
        candidates = await candidate_subscription_ids(self.session, training, user_id)
        if candidates:
            sub = await self.session.get(Subscription, candidates[0])
            lines.append(f"Будет списано с абонемента «{sub.name}» (осталось {sub.sessions_left})")
        elif prices.single_price:
            lines.append(f"К оплате: {format_money(prices.single_price)}")
        if prices.surcharge_per_person:
            going = await self.session.scalar(
                select(func.count()).select_from(Participation).where(
                    Participation.training_id == training_id, Participation.status == ParticipationStatus.GOING
                )
            )
            low, high = surcharge_estimate(prices.surcharge_per_person, going, training.capacity)
            lines.append(f"Доплата ≈ {format_range(low, high)} (зависит от числа участников)")
        return "\n".join(lines) or None
```

```python
        self, actor: User, training_id: int, user_id: int, present: bool, now: datetime
    ) -> AttendanceResult:

            raise PermissionDenied("Нет прав на эту тренировку")
        if actor.role != Role.ADMIN and now > training.ends_at + ATTENDANCE_WINDOW:
            raise InvalidAction("Прошло больше 72 часов: отметку может изменить только администратор")
        if await self.session.get(User, user_id) is None:
            raise NotFound("Пользователь не найден")
        if (user_id in await self.attendee_ids(training_id)) == present:
            return AttendanceResult()
        mark = await self.session.get(Attendance, (training_id, user_id))
        if mark is None:
            self.session.add(
                Attendance(training_id=training_id, user_id=user_id, present=present, marked_by=actor.telegram_id, marked_at=now)
            )
        else:
            mark.present, mark.marked_by, mark.marked_at = present, actor.telegram_id, now
        await self.session.flush()
        result = AttendanceResult(changed=True)
        if present:
            await self._reinstate(training, user_id, now)
        else:
            await self._void_charges(training_id, user_id, result)
        await self._recompute_surcharge(training, result)
        await self.session.commit()
        log.info("attendance training=%s user=%s present=%s by=%s", training_id, user_id, present, actor.telegram_id)
        return result

    async def _cond_update(self, charge_id: int, from_status: str, **values) -> bool:
        result = await self.session.execute(
            update(Charge)
            .where(Charge.id == charge_id, Charge.status == from_status)
            .values(**values)
            .execution_options(synchronize_session="fetch")
        )
        return result.rowcount == 1

    async def _void_charges(self, training_id: int, user_id: int, result: AttendanceResult) -> None:
        charges = await self.session.scalars(
            select(Charge).where(
                Charge.training_id == training_id, Charge.user_id == user_id, Charge.status != ChargeStatus.VOID
            )
        )
        for charge in list(charges):
            if await self._cond_update(charge.id, ChargeStatus.PENDING, status=ChargeStatus.VOID):
                continue
            if await self._cond_update(charge.id, ChargeStatus.PAID, status=ChargeStatus.VOID, refund_due=True):
                result.refund_due = True
                continue
            if await self._cond_update(charge.id, ChargeStatus.COVERED, status=ChargeStatus.VOID):
                returned = await self.session.execute(
                    update(Subscription)
                    .where(Subscription.id == charge.subscription_id, Subscription.sessions_left < Subscription.sessions_total)
                    .values(sessions_left=Subscription.sessions_left + 1)
                    .execution_options(synchronize_session="fetch")
                )
                if returned.rowcount == 1:
                    result.returned_to = (await self.session.get(Subscription, charge.subscription_id)).name

    async def _reinstate(self, training: Training, user_id: int, now: datetime) -> None:
        """«Пришёл» после «не пришёл» или без записи: оплаченное восстанавливается, остальное начисляется заново."""
        voided = await self.session.scalars(
            select(Charge).where(
                Charge.training_id == training.id, Charge.user_id == user_id, Charge.status == ChargeStatus.VOID
            )
        )
        for charge in list(voided):
            if charge.refund_due and charge.refunded_at is None:  # деньги ещё у клуба
                charge.status, charge.refund_due = ChargeStatus.PAID, False
            elif charge.refund_due:  # деньги уже вернули: ученик снова должен
                charge.status, charge.refund_due = ChargeStatus.PENDING, False
                charge.refunded_at = charge.paid_at = charge.paid_by = None
            else:
                await self.session.delete(charge)  # будет создано заново (и заново спишет единицу абонемента)
        await self.session.flush()
        prices = await self._prices(training)
        attendees = await self.attendee_ids(training.id)
        share = surcharge_share(prices.surcharge_per_person, len(attendees)) if prices.surcharge_per_person else None
        await self._charge_participant(training, user_id, prices, share, now, commit=False)

    async def _recompute_surcharge(self, training: Training, result: AttendanceResult) -> None:
        tariff = (await self._prices(training)).surcharge_per_person
        attendees = await self.attendee_ids(training.id)
        if not tariff or not attendees:
            return
        share = surcharge_share(tariff, len(attendees))
        rows = await self.session.scalars(
            select(Charge)
            .where(
                Charge.training_id == training.id,
                Charge.kind == ChargeKind.SURCHARGE,
                Charge.user_id.in_(attendees),
                Charge.status.in_([ChargeStatus.PENDING, ChargeStatus.PAID]),
            )
            .order_by(Charge.user_id)
        )
        for charge in list(rows):
            if charge.amount == share:
                continue
            if charge.status == ChargeStatus.PENDING:
                charge.amount = share
                result.pending_changes.append((charge.user_id, share))
            else:
                result.paid_diffs.append((charge.user_id, charge.amount, share))
```

```python
SUFFIX = {ChargeKind.SURCHARGE: " (доплата)", ChargeKind.INVENTORY: " (инвентарь)"}


def charge_label(charge: Charge, training: Training, tz: ZoneInfo) -> str:
    day = training.starts_at.astimezone(tz)
    return f"{day:%d.%m} · {KIND_NAMES.get(training.kind, training.kind)}{SUFFIX.get(charge.kind, '')}"


def render_new_charges(title: str, charges: list[Charge], sub_names: dict[int, str]) -> str:
    lines = [f"💳 {title}"]
    for charge in charges:
        if charge.kind == ChargeKind.SESSION and charge.status == ChargeStatus.COVERED:
            lines.append(f"✅ Списано с абонемента «{sub_names.get(charge.subscription_id, '—')}»")
        elif charge.kind == ChargeKind.SESSION:
            lines.append(f"К оплате: {format_money(charge.amount)}")
        elif charge.kind == ChargeKind.SURCHARGE:
            lines.append(f"➕ Доплата: {format_money(charge.amount)}")
        else:
            lines.append(f"🚲 Аренда инвентаря: {format_money(charge.amount)}")
    return "\n".join(lines)


def _history_line(charge: Charge, training: Training, tz: ZoneInfo) -> str:
    label = charge_label(charge, training, tz)
```

```python
from dataclasses import dataclass

from bot.billing.queries import Prices
from bot.core.errors import InvalidAction
from bot.core.money import MONEY_HINT, parse_money

PLAN_FORMAT = (
    "Одной строкой через «;»: Название; занятий; цена; срок в месяцах.\n"
    "Срок необязателен (по умолчанию 1), 0 — бессрочный.\n"
    "Пример: Утро+вечер; 8; 5500; 2"
)
PRICE_FORMAT = (
    "Одной строкой через «;»: разовая цена; доплата на человека (₽).\n"
    "«-» — не задано (берётся значение типа), 0 — бесплатно / без доплаты.\n"
    "Пример: 700; 500"
)


@dataclass(frozen=True)
class PlanDraft:
    name: str
    sessions: int
    price: int  # копейки
    valid_months: int | None  # None — бессрочный


def _int(text: str, what: str) -> int:
    try:
        return int(text.strip())
    except ValueError:
        raise InvalidAction(f"{what}: введите целое число.\n{PLAN_FORMAT}") from None


def parse_plan_line(text: str) -> PlanDraft:
    parts = [p.strip() for p in text.split(";")]
    if len(parts) not in (3, 4) or not parts[0]:
        raise InvalidAction(f"Название; занятий; цена; срок.\n{PLAN_FORMAT}")
    months: int | None = 1
    if len(parts) == 4:
        months = None if parts[3] in ("0", "-") else _int(parts[3], "Срок")
    return PlanDraft(parts[0], _int(parts[1], "Занятий"), parse_money(parts[2]), months)


def parse_prices_line(text: str) -> Prices:
    parts = [p.strip() for p in text.split(";")]
    if len(parts) not in (1, 2) or not parts[0]:
        raise InvalidAction(f"Введите сумму.\n{PRICE_FORMAT}")

    def one(value: str) -> int | None:
        return None if value == "-" else parse_money(value)

    try:
        return Prices(one(parts[0]), one(parts[1]) if len(parts) == 2 else None)
    except InvalidAction as exc:
        raise InvalidAction(f"{exc.message}\n{PRICE_FORMAT}") from None
```

```python
BACK_TO_PAY = [("⬅️ Меню", "pay:menu")]


def _id(cb: CallbackQuery, index: int = 2) -> int:
    return int(cb.data.split(":")[index])


def _money(value: int | None) -> str:
    return "—" if value is None else format_money(value)


@router.callback_query(F.data == "pay:menu")
async def on_menu(cb: CallbackQuery, user: User, state: FSMContext) -> None:
    require_admin(user)
    await state.clear()
    await safe_edit(cb.message, "💰 Оплаты", reply_markup=PAY_MENU)
    await cb.answer()


# ---------- должники ----------

async def _show_debtors(cb: CallbackQuery, session: AsyncSession) -> None:
    debtors = await BillingViews(session).debtors()
    rows = [[(f"👤 {d.user.name} · {format_money(d.total)}", f"pay:du:{d.user.telegram_id}")] for d in debtors]
    rows.append(BACK_TO_PAY)
    await safe_edit(cb.message, "Должники:" if debtors else "Долгов нет 🎉", reply_markup=markup(*rows))


@router.callback_query(F.data == "pay:debt")
async def on_debtors(cb: CallbackQuery, session: AsyncSession, user: User) -> None:
    require_admin(user)
    await _show_debtors(cb, session)
    await cb.answer()


async def _show_debtor(cb: CallbackQuery, session: AsyncSession, user_id: int) -> None:
    target = await session.get(User, user_id)
    if target is None:
        raise NotFound("Пользователь не найден")
    tz = await club_tz(session)
    view = await BillingViews(session).user_debts(user_id)
    rows = [
        [(f"✅ {charge_label(c, t, tz)} · {format_money(c.amount)}", f"pay:cp:{c.id}")] for c, t in view.charges
    ]
    rows += [[(f"✅ Абонемент «{s.name}» · {format_money(s.price)}", f"pay:sp:{s.id}")] for s in view.subscriptions]
    if view.charges or view.subscriptions:
        rows.append([("✅ Всё оплачено", f"pay:ua:{user_id}")])
    rows.append([("⬅️ К должникам", "pay:debt")])
    text = f"{target.name}: к оплате {format_money(view.total)}" if view.total > 0 else f"{target.name}: долгов нет"
    await safe_edit(cb.message, text, reply_markup=markup(*rows))

async def _plan_series_screen(session: AsyncSession, user: User, picked: list[int]) -> tuple[str, object]:
    series = await ScheduleService(session).active_series(user, utcnow())
    rows = [
        [(("☑️ " if s.id in picked else "⬜ ") + series_title(series_to_input(s)), f"pay:pst:{s.id}")] for s in series
    ]
    rows += [[("✅ Создать тариф", "pay:pok")], [("✖️ Отмена", "pay:menu")]]
    text = "Выберите серии, на которые действует абонемент:" if series else "Активных серий нет — создайте серию тренером."
    return text, markup(*rows)


@router.message(PlanForm.line, F.text, ~F.text.startswith("/"))
async def on_plan_line(message: Message, state: FSMContext, session: AsyncSession, user: User) -> None:
    require_admin(user)
    draft = parse_plan_line(message.text)  # неверный ввод: подсказка, состояние сохраняется
    await state.set_state(PlanForm.series)
    await state.update_data(
        draft={"name": draft.name, "sessions": draft.sessions, "price": draft.price, "valid_months": draft.valid_months},
        picked=[],
    )
    text, keyboard = await _plan_series_screen(session, user, [])
    await message.answer(text, reply_markup=keyboard)


@router.callback_query(PlanForm.series, F.data.regexp(r"^pay:pst:\d+$"))
async def on_plan_toggle(cb: CallbackQuery, state: FSMContext, session: AsyncSession, user: User) -> None:
    require_admin(user)
    series_id = _id(cb)
    picked = list((await state.get_data()).get("picked", []))
    picked = [i for i in picked if i != series_id] if series_id in picked else picked + [series_id]
    await state.update_data(picked=picked)
    text, keyboard = await _plan_series_screen(session, user, picked)
    await safe_edit(cb.message, text, reply_markup=keyboard)
    await cb.answer()


@router.callback_query(PlanForm.series, F.data == "pay:pok")
async def on_plan_create(cb: CallbackQuery, state: FSMContext, session: AsyncSession, user: User) -> None:
    data = await take_form(state, PlanForm.series, key="draft")
    if data is None:
        await cb.answer()
        return
    draft = data["draft"]
    try:
        plan = await CatalogService(session).create_plan(
            user, draft["name"], draft["sessions"], draft["price"], draft["valid_months"], data.get("picked", [])
        )
    except DomainError:
        await restore_form(state, PlanForm.series, data)
        raise
    log.info("plan %s created by %s", plan.id, user.telegram_id)
    await safe_edit(cb.message, f"Тариф «{plan.name}» создан", reply_markup=markup(BACK_TO_PAY))
    await cb.answer("Создан")
```

```python
router = Router()
router.callback_query.filter(F.message.chat.type == "private")


async def _managed(session: AsyncSession, user: User, training_id: int) -> Training:
    training = await session.get(Training, training_id)
    if training is None:
        raise NotFound("Тренировка не найдена")
    if not await can_manage(session, user, training):
        raise PermissionDenied("Нет прав на эту тренировку")
    return training


async def render_roster(session: AsyncSession, training: Training) -> tuple[str, InlineKeyboardMarkup]:
    roster = await BillingViews(session).roster(training.id)
    rows = [
        [(f"{'✅' if present else '❌'} {u.name}", f"att:t:{training.id}:{u.telegram_id}:{0 if present else 1}")]
        for u, present in roster
    ]
    rows += [[("➕ Пришёл без записи", f"att:add:{training.id}")], [("Готово", "att:done")]]
    tz = await club_tz(session)
    return f"Посещение: {short_title(training, tz)}\nНажмите на имя, чтобы изменить отметку.", markup(*rows)


@router.callback_query(F.data.regexp(r"^att:o:\d+$"))
async def on_open(cb: CallbackQuery, session: AsyncSession, user: User) -> None:
    training = await _managed(session, user, int(cb.data.split(":")[2]))
    text, keyboard = await render_roster(session, training)
    await safe_edit(cb.message, text, reply_markup=keyboard)
    await cb.answer()


@router.callback_query(F.data.regexp(r"^att:t:\d+:\d+:[01]$"))
async def on_toggle(cb: CallbackQuery, session: AsyncSession, messenger: Messenger, user: User) -> None:
    _, _, tid, uid, target = cb.data.split(":")
    training = await _managed(session, user, int(tid))
    result = await set_attendance(session, messenger, user, training.id, int(uid), target == "1", utcnow())
    text, keyboard = await render_roster(session, training)
    await safe_edit(cb.message, text, reply_markup=keyboard)
    await cb.answer("Отмечено" if result.changed else None)


@router.callback_query(F.data.regexp(r"^att:add:\d+$"))
async def on_add(cb: CallbackQuery, state: FSMContext, session: AsyncSession, user: User) -> None:
    training = await _managed(session, user, int(cb.data.split(":")[2]))
    await start_picker(cb, state, purpose="att_add", ctx={"tid": training.id}, prompt="Кто пришёл без записи?")


@on_pick("att_add")
async def picked_walk_in(
    cb: CallbackQuery, session: AsyncSession, user: User, messenger: Messenger, ctx: dict, picked_id: int
) -> None:

    await set_attendance(session, messenger, user, training.id, picked_id, True, utcnow())
    text, keyboard = await render_roster(session, training)
    await cb.message.answer(text, reply_markup=keyboard)
    await cb.answer("Отмечено")


@router.callback_query(F.data == "att:done")
async def on_done(cb: CallbackQuery) -> None:
    await safe_edit(cb.message, "Отметка посещения сохранена")
    await cb.answer()


@router.callback_query(F.data.startswith("att:"))
async def on_stale(cb: CallbackQuery) -> None:
    await cb.answer("Кнопка устарела", show_alert=True)
```
