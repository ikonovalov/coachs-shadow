# Меню на кнопках вместо слеш-команд — дизайн

Дата: 2026-10-06

## Цель

Пользователи и администраторы работают с ботом через inline-кнопки с тематическими иконками, а не через слеш-команды. Слеш-команды с аргументами (`/add_level`, `/bind_level`) заменяются диалогом и выбором из списка.

## Область

**В рамках задачи:**
- Главное меню по `/start`.
- Подменю администратора.
- Создание уровня через диалог (FSM).
- Привязка группового чата к уровню выбором из списка.
- Сужение списка команд в меню Telegram.

**Вне рамок:**
- Создание и отмена тренировок через кнопки (в боте этих команд пока нет).
- Постоянное хранилище FSM.
- Перевод `/whoami` на кнопки (остаётся командой по решению автора).

## Поведение

### Главное меню (`/start`, личный чат)

| Кнопка | Видна | Действие |
|---|---|---|
| 📅 Расписание | всем | Показывает ближайшие тренировки (как `/schedule`) |
| ⚙️ Админ | только админу | Открывает админ-меню |

### Админ-меню

| Кнопка | Действие |
|---|---|
| ➕ Новый уровень | Бот просит прислать название; следующее сообщение админа становится названием уровня |
| ⬅️ Назад | Возврат в главное меню |

Во время ввода названия доступна кнопка **✖️ Отмена**, которая сбрасывает состояние и возвращает админ-меню.

### Привязка чата (групповой чат)

`/bind_level` без аргумента отправляет список существующих уровней кнопками «🔗 *Название*». Нажатие привязывает чат к уровню. `/bind_level <название>` работает как раньше. Если уровней нет, бот отвечает подсказкой сначала создать уровень в личном чате.

### Команды

- `/start` и `/whoami` остаются и перечисляются в меню команд Telegram (`set_my_commands`).
- `/schedule` и `/add_level` остаются рабочим запасным путём, но в тексте бота и меню команд не упоминаются.
- Приветствие `/start` больше не ссылается на `/schedule`.

## Компоненты

- **`bot/telegram/menu.py`** (новый): построители клавиатур (главное меню, админ-меню, список уровней, отмена) и константы `callback_data`. Клавиатуры строятся как `InlineKeyboardMarkup`. Отделён от `keyboards.py`, который остаётся рендерером постов тренировок.
- **`bot/telegram/handlers/common.py`**: `/start` отправляет меню. Колбэки `menu:schedule`, `menu:admin`, `menu:back`.
- **`bot/telegram/handlers/schedule.py`**: тело `cmd_schedule` выносится в общую функцию, которую вызывают и команда, и кнопка.
- **`bot/telegram/handlers/admin.py`**: FSM `AddLevel` с одним состоянием «ожидание названия»; колбэки `admin:add_level`, `admin:cancel`, `bind:<level_id>`.
- **`bot/schedule/service.py`**: новый метод `list_levels()` (порядок по `position`, затем по имени).
- **`bot/main.py`**: `MemoryStorage` в `Dispatcher` и вызов `set_my_commands` со списком из `/start` и `/whoami`.

Правило проекта сохраняется: aiogram импортируется только внутри `bot/telegram/`.

## Поток данных

- **Админ нажимает «➕ Новый уровень»:** колбэк `admin:add_level` → проверка `require_admin` → состояние `AddLevel.waiting_name` → бот просит название. Следующее текстовое сообщение в этом состоянии → `ScheduleService.add_level(user, text)` → состояние очищается → бот подтверждает и возвращает админ-меню.
- **Привязка чата:** колбэк `bind:<level_id>` → `ScheduleService` находит уровень по id → `bind_chat(user, chat_id, title, level.name)`. Метод `bind_chat` по-прежнему принимает название, его сигнатура не меняется.
- **Меню в личном чате:** колбэки редактируют текущее сообщение (`edit_text`), а не присылают новое.

## Ошибки и права

- Роль проверяется на сервере (`require_admin` в сервисе и колбэках), а не только скрытием кнопки. Не-админ, нажавший устаревшую админскую кнопку, получает алерт «Только для администратора» через существующий обработчик в `bot/telegram/errors.py`.
- Пустое или слишком длинное название уровня отклоняется с подсказкой. Состояние остаётся, пока админ не пришлёт корректный текст или не нажмёт «Отмена».
- Если уровень из `bind:<level_id>` уже удалён, бот отвечает алертом «Уровень не найден».
- Колбэки `menu:*`, `admin:*` и `bind:*` проходят через `DbSessionMiddleware`, поэтому `session` и `user` доступны, как и в существующих хендлерах.
- `callback_data` не длиннее 64 байт.

## Ограничения

- `MemoryStorage` сбрасывается при рестарте бота. Для одношагового ввода это допустимо: админ просто повторит действие.
- Миграции БД и новые модели не требуются.
